# IDD-0007.spec-mvp-operability-and-quality

## Intent

The MVP remains responsive for typical desktop-browser use and provides
meaningful feedback instead of opaque geometry failures.

## Related Specifications

- IDD-0001
- IDD-0003
- IDD-0006

## Behavior

- For a typical SVG, import targets one second or less, 2D preview rebuild
  targets 300 ms or less, and STL generation targets three seconds or less. A
  heavier permitted SVG may take up to five seconds.
- The UI must not remain blocked for long computations. Heavy work can later
  move to a Web Worker without changing geometry behavior.
- Errors identify an actionable cause, such as the count of stroke-only paths,
  rather than returning a generic geometry error.
- Results are deterministic for identical SVG input, preset, caption, and
  settings, including bridge placement.

## Product-Significant Architecture And Constraints

- Published builds are restored, tested, published, and deployed to GitHub
  Pages only after tests succeed.

## Non-goals

- The targets do not require a visual drag-and-drop artwork editor or a manual
  CAD workflow.

## Acceptance Criteria

- Typical input meets the stated responsiveness targets on a modern desktop
  browser, or clear progress and error feedback is provided when limits apply.
- Identical inputs generate geometrically identical results.

## Verification

- Measure representative import, preview rebuild, and STL generation cases.
- Verify deterministic geometry and user-facing error messages.
