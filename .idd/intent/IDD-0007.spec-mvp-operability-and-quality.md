# IDD-0007.spec-mvp-operability-and-quality

## Intent

The MVP remains responsive for typical desktop-browser use and provides
meaningful feedback instead of opaque geometry failures.

## Related Specifications

- IDD-0001
- IDD-0003
- IDD-0006

## Behavior

- For a typical SVG, import targets one second or less, 2D preview rebuild
  targets 300 ms or less, and STL generation targets three seconds or less. A
  heavier permitted SVG may take up to five seconds.
- User-initiated processing is split into visible stages such as import,
  geometry construction, STL mesh construction, and download preparation, with
  browser-render opportunities between stages.
- Normal import and workspace editing never build an STL mesh. Their processing
  cost is limited to SVG flattening, polygon operations, topology, bridges,
  manufacturability analysis, and `CardGeometry` construction.
- Mesh construction and mesh validation occur only after the user requests an
  STL download.
- Inputs and export controls remain disabled until the active operation
  completes, including failure paths.
- Errors identify an actionable cause rather than returning a generic geometry
  error.
- Results are deterministic for identical SVG input, preset, caption, and
  settings, including bridge placement and STL output.

## Product-Significant Architecture And Constraints

- Published builds are restored, tested, published, and deployed to GitHub
  Pages only after tests succeed.
- Browser responsiveness is improved by avoiding unnecessary mesh work during
  editing; this specification does not require Web Workers or WASM
  multithreading for arbitrarily expensive 2D operations.

## Non-goals

- The targets do not require a visual drag-and-drop artwork editor or a manual
  CAD workflow.
- This specification does not promise uninterrupted interactivity during every
  permitted worst-case flattening or polygon operation.

## Acceptance Criteria

- Typical input meets the stated responsiveness targets on a modern desktop
  browser, or clear progress and error feedback is provided when limits apply.
- The `gat4.svg` regression fixture completes import, flattening, topology,
  bridges, and exportable `CardGeometry` construction without mesh generation.
- `gat4.svg` is separately exportable through the normal STL export path.
- Identical inputs generate geometrically identical results.

## Verification

- Measure representative import, 2D rebuild, and STL generation cases.
- Verify `gat4.svg` has an independent geometry-only regression and a separate
  STL export regression.
- Verify deterministic geometry and user-facing error messages.
