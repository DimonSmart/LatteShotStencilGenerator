# IDD-0004.spec-embossed-caption

## Intent

The MVP provides an optional embossed caption in the upper caption area; it is
distinct from a future text-as-stencil feature.

## Related Specifications

- IDD-0001
- IDD-0002
- IDD-0006

## Behavior

- After SVG upload, `Caption` defaults to the uppercase source filename without
  extension. Users can edit it; an empty caption means no caption.
- Caption text is centred in the caption area. Its target height is about
  12.25 mm, it shrinks to fit width, and never exceeds its configured maximum.
- Text becomes closed vector glyph outlines embossed 0.354 mm above the raised
  outer/header surface; it never cuts through the card.
- Users choose from several bundled caption fonts including a default. The
  selected font is stored in project state and the preset supplies only the
  default. Preview and STL use the same glyph outlines.
- Bundled font licences permit public open-source distribution. System browser
  fonts are not used as STL geometry sources, and equal text, font, and settings
  produce equal geometry.

## Product-Significant Architecture And Constraints

- The font-selection UI may grow without changing stencil or mesh behavior.

## Non-goals

- Exact `Donut.stl` font recovery, arbitrary text as stencil holes, multiline
  text, and font-face styling are not MVP requirements.

## Acceptance Criteria

- `donut.svg` initially yields caption `DONUT`.
- A default `DONUT` caption is centred in the caption area, reaches about
  12.25 mm when space permits, and raises the reference top to about 1.552 mm.

## Verification

- Verify filename derivation, empty-caption behavior, fit-to-width,
  deterministic glyph geometry, caption centring, and expected Z level.
