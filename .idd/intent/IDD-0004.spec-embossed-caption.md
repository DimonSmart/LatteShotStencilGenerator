# IDD-0004.spec-embossed-caption

## Intent

The stencil may carry an optional human-readable caption on the template. Text
is real printable geometry and may also be assigned a distinct 3MF
color/material so a multi-material printer can distinguish it from the base
template.

## Related Specifications

- IDD-0001
- IDD-0002
- IDD-0006

## Behavior

- Caption text is optional. Empty text produces no caption geometry.
- A new artwork file may initialize the caption from its filename, but the user
  can freely replace or clear it.
- The user chooses a bundled font and controls caption X/Y position and text
  size in template-local millimetres.
- The reference-card defaults place the caption inside the reference caption
  rectangle from IDD-0002.
- Caption glyphs are converted to deterministic closed vector outlines and
  embossed onto the top-facing template surface. The default emboss height is
  approximately 0.35 mm and is configurable.
- The application prevents caption geometry from being placed completely
  outside the template and reports intersections or unsupported placement that
  would make the result unprintable.
- The user can choose a base preview/export color and a separate caption color.
  Colors are visual metadata in 3MF; STL export contains only the physical
  geometry.
- The color-region model is extensible to an optional accent band around the
  artwork opening. When such an accent is enabled, it has its own width and
  color/material and must not alter the intended opening unless the UI
  explicitly presents a geometric accent option.
- Bundled font licences must permit public distribution with the static site.
  System-installed fonts are not used as geometry sources because identical
  project state must generate identical glyph outlines.

## Product-Significant Architecture And Constraints

- Caption and color/material settings are part of project state and preview.
- Font-library types do not become stencil-engine contracts.
- Color/material assignment is preserved separately from physical geometry so
  STL and 3MF can be generated from the same design state.

## Non-goals

- Multiline layout, arbitrary font uploads, rich text, and text used as a
  through-cut stencil are outside the initial scope.

## Acceptance Criteria

- A user can select a bundled font, enter text, position it with X/Y controls,
  choose its size, and see the embossed caption in the 3D preview.
- STL contains the caption geometry without relying on color.
- 3MF can assign the caption a different color/material from the base template.
- Equal text, font, placement, and size produce equal caption geometry.

## Verification

- Verify empty caption behavior, filename-derived default, font selection,
  position/size controls, deterministic outlines, printable embossing, and
  distinct 3MF caption color.
