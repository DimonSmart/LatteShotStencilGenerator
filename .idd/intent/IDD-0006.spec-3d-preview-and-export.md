# IDD-0006.spec-3d-preview-and-export

## Intent

The interactive 3D preview is a compact visual check of the actual uploaded
template and current generated stencil. It stays secondary to the editing
controls by default and can be expanded across the browser viewport for detailed
inspection without creating a second render scene. Export supports both
geometry-only STL and color/material-capable 3MF.

## Behavior

- The 3D viewport displays the current template and generated result with orbit,
  zoom, pan, fit-to-model, and a reliable top view for checking artwork
  orientation.
- In the normal workspace the preview has a bounded size independent of the
  height of the settings content, so the complete preview remains visible as a
  quick visual check on typical desktop viewports.
- The same preview can be expanded over most of the browser viewport and closed
  again with the preview control or Escape. Expansion reuses the existing
  renderer, scene, canvas, camera, and controls; camera orientation is preserved
  when returning to compact mode.
- The preview can show the artwork working rectangle and other placement guides
  without baking those guides into exported geometry.
- After a valid template and SVG are loaded, the preview shows the real
  through-cut, automatic bridges, optional caption, and current color/material
  choices.
- Stale geometry results from superseded edits are never allowed to replace a
  newer preview.
- STL export is binary and contains the complete printable physical geometry as
  one geometry-only result. Coordinates use the millimetre convention even
  though STL itself does not encode units or reliable color metadata.
- 3MF export declares millimetres and preserves supported color/material
  distinctions such as base template and caption. Optional supported accent
  regions use their own material/color assignment.
- If the input is a colored 3MF, the application preserves usable source color
  information where it can do so without compromising geometry operations;
  otherwise it clearly falls back to the chosen base color rather than
  pretending full source-material fidelity.
- Export validates non-empty finite geometry and catches manifold/watertight
  failures before offering a file.
- An export failure does not clear the loaded template, SVG, placement, bridges,
  caption, or color choices.

## Product-Significant Architecture And Constraints

- The render scene is not the authoritative geometry model. Rendering objects
  are derived from project-owned geometry state.
- Compact/expanded preview state is transient UI state and is not part of the
  generated project settings or geometry state.
- STL and 3MF are two serializations of the same current design intent. Their
  physical geometry must agree within normal numeric/export tolerance.
- 3MF output follows the 3MF Core specification and the standard
  material/color mechanisms required by the selected color regions.

## Non-goals

- Browser Fullscreen API integration is not required; expanded preview means a
  browser-viewport overlay inside the application.
- Slicer project settings, printer profiles, supports, toolpaths, and vendor
  proprietary paint metadata are not part of the exported design.
- Triangle ordering parity with the input template is not required.

## Acceptance Criteria

- The compact viewport lets the user immediately verify the current result
  without growing to match a long settings panel.
- The same viewport can be expanded for detailed inspection and restored with
  its current camera orientation intact.
- Top view, fit model, orbit, zoom, and pan remain available in compact and
  expanded modes.
- Downloaded STL is printable geometry and opens correctly in common slicers.
- Downloaded 3MF retains model scale and supported base/caption color
  distinctions in common 3MF-aware slicers.
- The top view of both exported formats matches the preview orientation.
- Geometry/export errors leave the editable project state intact.

## Verification

- Verify bounded compact preview sizing on representative desktop and narrow
  viewports, then expand/restore it with the button and Escape.
- Compare preview and exported bounding boxes and orientation.
- Validate STL watertight/manifold properties.
- Inspect 3MF package/unit/material data and open representative files in
  OrcaSlicer plus at least one of Bambu Studio or PrusaSlicer.
