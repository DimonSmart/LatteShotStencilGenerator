# IDD-0001.spec-product-overview

## Intent

Latte Shot Stencil Generator is a static, browser-only tool for turning an
existing 3D stencil template plus vector artwork into a printable coffee-stencil
model. The user supplies the physical template geometry, positions SVG artwork
inside a defined working area, and the application cuts that artwork through the
template, automatically preserves otherwise detached islands with bridges, and
exports the result for 3D printing.

The application is implemented as JavaScript/TypeScript and is designed to be
hosted as a static GitHub Pages site.

## Behavior

- The primary workflow starts from a 3D template loaded from STL. 3MF template
  import is also supported so the application can evolve toward richer
  multi-material workflows.
- The template is the source of truth for the card shape. It may be rectangular,
  round, or another plate-like printable shape; the application does not
  regenerate the outer card from a fixed preset.
- The user defines an axis-aligned artwork working rectangle relative to the
  template's top-view bounds using left, right, top, and bottom margins.
- The user loads fill-based SVG artwork. The artwork is fitted into the working
  rectangle, can be repositioned and scaled, and becomes a through-cut in the
  uploaded 3D template.
- If cutting the artwork would create detached retained-material islands, the
  application automatically creates printable bridges and rechecks the result.
- The user may add an optional text caption using a bundled font and explicit
  position/size settings relative to the template.
- The main preview is the current 3D result rather than a synthetic replacement
  card. The user can inspect the uploaded template, cut artwork, bridges,
  caption, and color/material regions.
- The final model can be downloaded as STL and as 3MF. STL represents geometry
  only. 3MF is the color/material-capable output and can distinguish the base
  template, caption, and other supported accent regions.
- Invalid input or geometry blocks export with an actionable explanation instead
  of silently changing the design.

## Product-Significant Architecture And Constraints

- All user files are processed locally in the browser. There is no backend,
  account, database, upload service, or server-side geometry processing.
- User files remain local to the tab and are not transmitted to a server.
- The published application works from a GitHub Pages project subpath, including
  direct navigation and reload, without root-bound asset assumptions.
- The product works in millimetres internally.
- Expensive geometry work must not require a C#/.NET runtime in the browser.

## Non-goals

- Raster image tracing, a general-purpose CAD editor, arbitrary mesh sculpting,
  cloud processing, automatic repair of severely broken meshes, and manual
  per-triangle editing are outside the initial scope.
- The initial placement model is planar: artwork is projected from the
  template's top side and cut through the template thickness. Wrapping artwork
  over curved surfaces is outside scope.
- Manual bridge placement is not required initially.

## Acceptance Criteria

- A user can load a valid stencil template, load a valid SVG, define or accept a
  working area, preview the result, and download printable STL and 3MF files
  entirely in the browser.
- The SVG cut seen from the template's top side has the same visual orientation
  as the source artwork; it is not accidentally mirrored or rotated.
- Designs with enclosed artwork regions such as O, 8, A, or enclosed logo
  details remain a single printable stencil after automatic bridging.
- The app can be deployed to GitHub Pages without a server and without shipping
  a .NET runtime.
- User model and artwork bytes are never uploaded.

## Verification

- Exercise the complete template-to-SVG-to-bridge-to-preview-to-STL/3MF workflow
  in a deployed static build.
- Verify with an asymmetric SVG that the final top-side cut is neither mirrored
  nor upside down.
- Verify no network request contains uploaded template or artwork data.
