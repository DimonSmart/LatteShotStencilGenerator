# IDD-0001.spec-product-overview

## Intent

Latte Card Generator is a static, browser-only application that creates a
3D-printable stencil card from an SVG artwork file. The MVP lets a person upload
an SVG, review the final 2D stencil geometry, adjust supported settings, and
download a binary STL without CAD knowledge or a server-side service.

## Behavior

- The default selected preset is `Reference / Donut`.
- A successful SVG upload creates a useful 2D card preview without mandatory
  edits.
- The application provides controls for preset, upload, caption and its font,
  stencil inversion, scale/offsets, card and bridge settings, reset, warnings,
  and STL download. Advanced settings may be collapsed.
- The primary workspace provides a 2D representation of the final stencil
  geometry, validation status, and STL export.
- Download is unavailable while a critical configuration, import, or geometry
  validation error exists.

## Product-Significant Architecture And Constraints

- The 2D `CardGeometry` is the workspace model. Editing the workspace does not
  create or validate an STL mesh.
- The STL mesh is a temporary export artifact created only when the user
  requests a download.
- The MVP runs entirely in the browser as a static site: it has no backend,
  accounts, database, or server-side processing.
- User SVG files are processed locally, remain only in tab memory, are never
  sent to a server, and are discarded on page reload.
- The published app works from a GitHub Pages project subpath, including direct
  navigation and reload, without root-bound absolute paths.

## Non-goals

- Raster tracing, 3MF export, project save/load, template galleries, a full
  text-as-stencil mode, contour editing, manual bridge placement, cloud
  processing, and colour printing are outside MVP scope.

## Acceptance Criteria

- A person can upload a valid SVG, inspect the final 2D stencil geometry, and
  download a valid STL entirely in the browser.
- Editing SVG placement, bridges, caption, inversion, or 2D limits does not
  build an STL mesh.
- The app can be deployed to GitHub Pages and works from its project subpath.
- User artwork is not transmitted outside the browser.

## Verification

- Exercise the upload-to-download scenario in a deployed static build.
- Verify workspace editing updates only 2D geometry and does not invoke mesh
  generation before STL download.
- Verify network activity does not upload SVG data and that direct navigation
  and reload work under a GitHub Pages subpath.
