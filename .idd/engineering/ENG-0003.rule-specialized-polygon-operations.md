# ENG-0003.rule-specialized-polygon-operations

## Rule

Use Clipper2 through project-owned polygon geometry contracts for planar polygon normalization, boolean operations, and offsets. Use LibTessDotNet only to triangulate final normalized polygon geometry.

## Applicability

Conditional

## Applies when

- implementing planar vector geometry, polygon normalization, stencil topology, bridges, caption-contour union, or mesh triangulation

## Rationale

Robust planar boolean operations and triangulation are distinct concerns. Keeping them behind project-owned geometry contracts prevents library-specific types and ad-hoc polygon algorithms from becoming cross-layer contracts.

## Guidance

Expose canonical project-owned polygon geometry to the stencil and mesh layers. Do not reintroduce local containment, overlap-resolution, or offset implementations downstream of the polygon engine. The SVG and caption adapters may supply project-owned contours but must not expose their library types outside their adapters.

## Verification

Overlapping, touching, nested, and holed contours normalize to explicit canonical polygon geometry; bridge operations use that geometry; final triangulation produces valid mesh input without polygon boolean work in the mesh layer.
