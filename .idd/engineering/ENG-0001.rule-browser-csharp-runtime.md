# ENG-0001.rule-browser-csharp-runtime

## Rule

Implement the regenerated application as a browser-native JavaScript/TypeScript
static site. Do not use C#, .NET, Blazor WebAssembly, or another managed runtime
as an application dependency.

Use Vite as the default build tool unless a concrete repository constraint
requires an equivalent static bundler.

## Applicability

Always

## Rationale

The product is intended to be a lightweight GitHub Pages application and the
new geometry stack is centered on mature JavaScript and WebAssembly libraries.
Removing the .NET runtime also removes a layer that previously complicated
browser-side geometry and responsiveness.

## Guidance

- Prefer TypeScript for application code and library boundaries.
- Bundle runtime dependencies and WASM assets into the static build rather than
  relying on a server.
- Keep asset URLs compatible with a GitHub Pages project subpath.
- Do not preserve C# abstractions merely because they existed in the previous
  implementation.

## Verification

The production artifact is ordinary static HTML/CSS/JavaScript/WASM, works from
the configured GitHub Pages subpath, and contains no Blazor/.NET runtime.
