# ENG-0002.rule-isolate-svg-and-font-adapters

## Rule

Isolate SVG-processing and caption-font dependencies behind adapters so either
dependency can be replaced without rewriting the stencil engine.

## Applicability

Conditional

## Applies when

- adding or changing SVG import, SVG geometry conversion, caption-font loading,
  or caption glyph-outline integration

## Rationale

SVG and font libraries are external dependencies while stencil generation is a
separate durable product concern.

## Guidance

Keep adapter contracts focused on normalised geometry or glyph-outline data; do
not let library-specific types become stencil-engine contracts.

## Verification

The stencil engine consumes project-owned geometry contracts, and a selected SVG
or font library can be substituted without changing its behavior contract.
